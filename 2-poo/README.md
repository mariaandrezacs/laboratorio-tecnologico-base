# POO - Programação Orientada a Objetos

## Roteiro de estudo

### 1. Conceitos básicos
- Entenda o que é Programação Orientada a Objetos
- Saiba a diferença entre:
  - classe
  - objeto
  - instância
  - atributo
  - método

### 2. Princípios fundamentais
- Aprenda os 4 pilares:
  - Encapsulamento
  - Herança
  - Polimorfismo
  - Abstração

### 3. Modelagem de classes
- Pratique criar classes simples:
  - `Pessoa`, `Carro`, `ContaBancaria`
- Defina atributos e métodos
- Use construtores para inicializar objetos

### 4. Relacionamentos entre classes
- Estude:
  - associação
  - agregação
  - composição
- Veja quando uma classe “tem” outra classe

### 5. Regras de acesso
- Use:
  - `public`
  - `private`
  - `protected`
- Entenda por que proteger o estado interno é importante

### 6. Polimorfismo e herança prática
- Crie uma hierarquia:
  - `Animal` → `Cachorro`, `Gato`
- Implemente métodos sobrescritos (`override`)
- Use tipos gerais para referenciar objetos específicos

### 7. Boas práticas
- Separe responsabilidades
- Evite classes muito grandes
- Nomeie métodos e atributos claramente
- Prefira métodos pequenos e objetivos

### 8. Projetos simples
- Faça pequenos exercícios:
  - sistema de biblioteca
  - cadastro de alunos
  - controle de estoque
- Tente manter código organizado em várias classes

## Como seguir
1. Estude cada tópico em ordem.
2. Faça exercícios práticos com uma linguagem que conheça.
3. Revise os conceitos enquanto progride.
4. A cada novo exemplo, tente alterar e testar o comportamento.
