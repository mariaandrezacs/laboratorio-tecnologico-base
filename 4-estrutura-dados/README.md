# Roteiro de Aprendizado - Estrutura de Dados

Este roteiro foi desenvolvido para guiar você no aprendizado de estruturas de dados, fundamentais para escrever algoritmos eficientes e resolver problemas complexos.

## 📋 Estrutura do Roteiro

O roteiro está organizado em módulos progressivos. Cada módulo deve ser concluído antes de avançar para o próximo.

---

## 🎯 Módulo 1: Fundamentos de Estruturas de Dados

### Objetivos
- Compreender o que são estruturas de dados
- Entender a importância de escolher a estrutura adequada
- Aprender sobre complexidade de algoritmos

### Tópicos
1. **O que são Estruturas de Dados?**
   - Definição e propósito
   - Diferença entre dados e estrutura de dados
   - Por que são importantes

2. **Tipos de Estruturas de Dados**
   - Estruturas lineares
   - Estruturas não lineares
   - Estruturas primitivas vs compostas

3. **Análise de Complexidade**
   - Notação Big O
   - Complexidade de tempo
   - Complexidade de espaço
   - Melhor, pior e caso médio

### Recursos Recomendados
- [Cracking the Coding Interview](https://www.crackingthecodinginterview.com/)
- [GeeksforGeeks - Data Structures](https://www.geeksforgeeks.org/data-structures/)
- [YouTube - Alura](https://www.youtube.com/@Alura)

### Exercícios Práticos
- Analisar complexidade de algoritmos simples
- Comparar diferentes estruturas para o mesmo problema
- Identificar a estrutura de dados adequada para cenários

## 📚 Módulo 2: Arrays e Listas

### Objetivos
- Dominar o uso de arrays
- Compreender listas encadeadas
- Comparar vantagens e desvantagens

### Tópicos
1. **Arrays (Vetores)**
   - O que são arrays
   - Acesso por índice
   - Inserção e remoção
   - Arrays multidimensionais
   - Arrays dinâmicos (ArrayList, Vector)

2. **Listas Encadeadas (Linked Lists)**
   - Lista simplesmente encadeada
   - Lista duplamente encadeada
   - Lista circular
   - Operações básicas (inserção, remoção, busca)

3. **Comparação: Arrays vs Listas**
   - Performance de acesso
   - Performance de inserção/remoção
   - Uso de memória
   - Quando usar cada um

### Exercícios Práticos
- Implementar uma lista encadeada do zero
- Criar funções para inserir, remover e buscar elementos
- Implementar reversão de lista encadeada
- Detectar ciclos em uma lista
- Mesclar duas listas ordenadas

## 📦 Módulo 3: Pilhas e Filas

### Objetivos
- Compreender o conceito LIFO e FIFO
- Implementar pilhas e filas
- Aplicar em problemas práticos

### Tópicos
1. **Pilhas (Stacks)**
   - Conceito LIFO (Last In, First Out)
   - Operações: push, pop, peek
   - Implementação com array
   - Implementação com lista encadeada
   - Aplicações práticas

2. **Filas (Queues)**
   - Conceito FIFO (First In, First Out)
   - Operações: enqueue, dequeue, peek
   - Implementação com array
   - Implementação com lista encadeada
   - Filas circulares

3. **Filas de Prioridade**
   - Conceito de prioridade
   - Heap como implementação
   - Operações básicas
   - Aplicações

### Exercícios Práticos
- Implementar uma pilha usando arrays
- Implementar uma fila usando listas encadeadas
- Verificar expressões balanceadas com pilha
- Implementar uma fila de prioridade
- Resolver problemas de navegação com pilhas

---

## 🗂️ Módulo 4: Árvores

### Objetivos
- Compreender estruturas hierárquicas
- Aprender diferentes tipos de árvores
- Dominar operações em árvores

### Tópicos
1. **Árvores Binárias**
   - Conceitos básicos (raiz, nó, folha, altura)
   - Árvore binária completa
   - Árvore binária cheia
   - Percurso em árvores (in-order, pre-order, post-order)

2. **Árvores de Busca Binária (BST)**
   - Propriedades da BST
   - Inserção e remoção
   - Busca eficiente
   - Balanceamento

3. **Árvores Balanceadas**
   - AVL Tree
   - Red-Black Tree
   - Quando usar árvores balanceadas

4. **Árvores N-árias**
   - Árvores genéricas
   - B-Trees
   - Aplicações em bancos de dados

### Exercícios Práticos
- Implementar uma árvore binária de busca
- Implementar os três tipos de percurso
- Verificar se uma árvore é balanceada
- Encontrar o ancestral comum mais baixo
- Converter árvore em lista encadeada

## 🕸️ Módulo 5: Grafos

### Objetivos
- Compreender representação de grafos
- Aprender algoritmos de busca em grafos
- Aplicar grafos em problemas reais

### Tópicos
1. **Conceitos de Grafos**
   - Vértices e arestas
   - Grafos direcionados vs não direcionados
   - Grafos ponderados
   - Grafos conectados vs desconectados

2. **Representação de Grafos**
   - Matriz de adjacência
   - Lista de adjacência
   - Comparação entre representações

3. **Algoritmos de Busca**
   - BFS (Breadth-First Search)
   - DFS (Depth-First Search)
   - Aplicações de cada algoritmo

4. **Algoritmos de Caminho Mínimo**
   - Dijkstra
   - Bellman-Ford
   - Floyd-Warshall

5. **Algoritmos de Árvore Geradora Mínima**
   - Prim
   - Kruskal

### Exercícios Práticos
- Implementar representação de grafo com lista de adjacência
- Implementar BFS e DFS
- Encontrar caminho mais curto em um grafo ponderado
- Detectar ciclos em um grafo
- Resolver problemas de conectividade

## 🔍 Módulo 6: Hash Tables

### Objetivos
- Compreender o funcionamento de hash tables
- Aprender sobre funções de hash
- Entender colisões e resolução

### Tópicos
1. **Conceitos de Hash**
   - O que é uma função de hash
   - Propriedades de uma boa função de hash
   - Hash tables e dicionários

2. **Colisões**
   - O que são colisões
   - Encadeamento separado
   - Endereçamento aberto
   - Linear probing, quadratic probing

3. **Performance**
   - Caso médio O(1)
   - Pior caso O(n)
   - Fator de carga
   - Rehashing

### Exercícios Práticos
- Implementar uma hash table simples
- Implementar função de hash
- Lidar com colisões usando encadeamento
- Criar um sistema de cache com hash table
- Implementar um contador de frequência

## 🗃️ Módulo 7: Estruturas Avançadas

### Objetivos
- Explorar estruturas de dados mais complexas
- Entender aplicações específicas
- Compreender trade-offs

### Tópicos
1. **Heaps**
   - Min-Heap e Max-Heap
   - Implementação com array
   - Operações: insert, extract-min/max
   - Heap sort
   - Priority Queue

2. **Tries (Prefix Trees)**
   - Estrutura de trie
   - Inserção e busca
   - Autocompletar
   - Spell checking

3. **Segment Trees**
   - Consultas de intervalo
   - Atualizações pontuais
   - Aplicações em problemas de range

4. **Fenwick Trees (Binary Indexed Trees)**
   - Consultas de soma de prefixo
   - Atualizações eficientes
   - Comparação com Segment Trees

### Exercícios Práticos
- Implementar um min-heap
- Usar heap para encontrar k maiores elementos
- Implementar uma trie para autocompletar
- Resolver problemas de range query com segment tree
- Implementar contador de frequência com Fenwick tree

## 🎮 Módulo 8: Algoritmos de Ordenação

### Objetivos
- Dominar algoritmos de ordenação
- Compreender complexidade de cada algoritmo
- Saber quando usar cada um

### Tópicos
1. **Ordenação Simples**
   - Bubble Sort
   - Selection Sort
   - Insertion Sort
   - Complexidade e uso

2. **Ordenação Eficiente**
   - Merge Sort
   - Quick Sort
   - Heap Sort
   - Comparação de performance

3. **Ordenação Especializada**
   - Counting Sort
   - Radix Sort
   - Bucket Sort
   - Quando usar ordenação não comparativa

## 🧩 Módulo 9: Algoritmos de Busca

### Objetivos
- Dominar técnicas de busca
- Compreender busca em diferentes estruturas
- Aplicar busca em problemas práticos

### Tópicos
1. **Busca Linear**
   - Conceito e implementação
   - Complexidade O(n)
   - Quando usar

2. **Busca Binária**
   - Pré-requisitos (array ordenado)
   - Implementação iterativa e recursiva
   - Complexidade O(log n)
   - Variações (lower bound, upper bound)

3. **Busca em Estruturas de Dados**
   - Busca em árvores BST
   - Busca em hash tables
   - Busca em grafos

4. **Técnicas de Busca Avançadas**
   - Busca binária em matriz
   - Busca exponencial
   - Interpolation search

### Exercícios Práticos
- Implementar busca linear e binária
- Encontrar primeiro e último elemento em array ordenado
- Buscar em matriz 2D ordenada
- Implementar busca em rotação de array
- Resolver problemas de busca em estruturas complexas

## 🎯 Dicas de Estudo

1. **Implemente do zero** - Não use bibliotecas prontas, implemente você mesmo
2. **Desenhe as estruturas** - Visualize o que está acontecendo
3. **Analise a complexidade** - Sempre pense em Big O
4. **Pratique regularmente** - Resolva problemas diariamente
5. **Ensine o que aprendeu** - Explique reforça o conhecimento
6. **Compare abordagens** - Entenda os trade-offs
7. **Use debug visual** - Ferramentas como VisualAlgo ajudam muito
