# Roteiro de Aprendizado - Lógica de Programação

Este roteiro foi desenvolvido para guiar você no aprendizado sólido de lógica de programação, desde os conceitos básicos até tópicos mais avançados.

## 📋 Estrutura do Roteiro

O roteiro está organizado em módulos progressivos. Cada módulo deve ser concluído antes de avançar para o próximo, garantindo uma base sólida.

---

## 🎯 Módulo 1: Fundamentos e Conceitos Básicos

### Objetivos
- Compreender o que é lógica de programação
- Entender o funcionamento básico de computadores
- Aprender sobre algoritmos

### Tópicos
1. **O que é Lógica de Programação?**
   - Definição e importância
   - Diferença entre lógica e sintaxe
   - Por onde começar

2. **Conceitos Fundamentais**
   - O que é um algoritmo
   - Entrada, Processamento e Saída
   - Variáveis e Constantes
   - Tipos de dados (inteiro, real, texto, booleano)

3. **Pensamento Computacional**
   - Decomposição de problemas
   - Reconhecimento de padrões
   - Abstração
   - Design de algoritmos

### Recursos Recomendados
- [Curso em Vídeo - Lógica de Programação](https://www.cursoemvideo.com/curso/logica-de-programacao/)
- [YouTube - Guanabara](https://www.youtube.com/@cursoemvideo)
- Livro: "Lógica de Programação" de André Forga

### Exercícios Práticos
- Criar algoritmos simples para tarefas do dia a dia
- Escrever pseudocódigo para problemas básicos
- Identificar entradas, processamentos e saídas em situações reais

---

## 🔢 Módulo 2: Estruturas de Controle

### Objetivos
- Dominar o fluxo de execução de programas
- Aprender a tomar decisões no código
- Controlar repetições de forma eficiente

### Tópicos
1. **Estruturas de Decisão**
   - Estrutura SE/SENAO (if/else)
   - Estrutura CASO (switch/case)
   - Operadores lógicos (E, OU, NÃO)
   - Operadores relacionais (==, !=, >, <, >=, <=)

2. **Estruturas de Repetição**
   - ENQUANTO (while)
   - PARA (for)
   - REPITA (do-while)
   - Diferenças e quando usar cada uma

3. **Comandos de Controle de Fluxo**
   - BREAK
   - CONTINUE
   - Boas práticas no uso de loops

### Exercícios Práticos
- Verificar se um número é par ou ímpar
- Calcular média de notas
- Imprimir números de 1 a N
- Encontrar o maior número em uma lista
- Tabuada completa
- Fatorial de um número

---

## 📚 Módulo 3: Estruturas de Dados Básicas

### Objetivos
- Compreender como organizar e armazenar dados
- Aprender a manipular coleções de informações

### Tópicos
1. **Vetores (Arrays)**
   - O que são e quando usar
   - Declaração e inicialização
   - Acesso e modificação de elementos
   - Percorrendo vetores

2. **Matrizes**
   - Conceito de matrizes bidimensionais
   - Operações com matrizes
   - Aplicações práticas

3. **Strings (Cadeias de Caracteres)**
   - Manipulação de texto
   - Operações comuns (concatenação, substring, etc.)
   - Formatação

### Exercícios Práticos
- Armazenar notas de alunos em vetor
- Calcular estatísticas de um conjunto de números
- Manipular textos (inverter, contar caracteres, etc.)
- Jogo da velha usando matriz
- Criar um sistema simples de cadastro

---

## 🧩 Módulo 4: Funções e Modularização

### Objetivos
- Aprender a organizar código em blocos reutilizáveis
- Compreender escopo de variáveis
- Desenvolver código mais limpo e manutenível

### Tópicos
1. **Conceitos de Funções**
   - O que são e por que usar
   - Parâmetros e argumentos
   - Retorno de valores
   - Funções com e sem retorno

2. **Escopo de Variáveis**
   - Variáveis locais vs globais
   - Boas práticas de escopo
   - Passagem de parâmetros

3. **Modularização**
   - Dividir problemas em subproblemas
   - Reutilização de código
   - Documentação de funções

### Exercícios Práticos
- Criar função para calcular IMC
- Função para validar CPF
- Modularizar um sistema de cálculo de notas
- Criar biblioteca de funções matemáticas

---

## 🔍 Módulo 5: Algoritmos de Busca e Ordenação

### Objetivos
- Aprender algoritmos fundamentais
- Compreender complexidade básica
- Desenvolver pensamento algorítmico

### Tópicos
1. **Algoritmos de Busca**
   - Busca linear
   - Busca binária
   - Quando usar cada uma

2. **Algoritmos de Ordenação**
   - Bubble Sort
   - Selection Sort
   - Insertion Sort
   - Comparação entre algoritmos

3. **Conceitos de Complexidade**
   - O que é complexidade
   - Notação Big O básica
   - Eficiência de algoritmos

### Exercícios Práticos
- Implementar busca linear em um vetor
- Implementar busca binária em vetor ordenado
- Ordenar uma lista usando diferentes métodos
- Comparar tempo de execução entre algoritmos

## 🎯 Dicas de Estudo

1. **Pratique diariamente** - Consistência é mais importante que intensidade
2. **Não copie código** - Tente entender e recriar por conta própria
3. **Desenhe fluxogramas** - Ajuda a visualizar a lógica
4. **Ensine o que aprendeu** - Explicar reforça o conhecimento
5. **Resolva problemas reais** - Aplique em situações do dia a dia
6. **Não tenha medo de errar** - Erros fazem parte do aprendizado
7. **Use o pseudocódigo** - Escreva antes de codificar
