# Laboratório Tecnológico

Laboratório de aprendizado para iniciantes em desenvolvimento de software. Este repositório contém roteiros estruturados para construir uma base sólida em programação e desenvolvimento.

## 📚 Estrutura do Laboratório

O laboratório está organizado em módulos progressivos. Cada módulo deve ser concluído antes de avançar para o próximo, garantindo uma base sólida.

### Módulos Fundamentais

1. **[Lógica de Programação](./logica-de-programacao/)** - Base essencial para qualquer programador
2. **[POO - Programação Orientada a Objetos](./poo/)** - Paradigma fundamental para desenvolvimento de software
3. **[Git e Controle de Versão](./git-controle-versao/)** - Essencial para trabalho em equipe e gestão de código
4. **[Estrutura de Dados](./estrutura-dados/)** - Fundamentos para algoritmos eficientes
5. **[Banco de Dados](./banco-dados/)** - Persistência e gestão de dados
6. **[Desenvolvimento Web Frontend](./web-frontend/)** - HTML, CSS, JavaScript e frameworks modernos
7. **[Desenvolvimento Web Backend](./web-backend/)** - APIs, REST e arquitetura de servidor
8. **[Testes de Software](./testes/)** - Qualidade e confiabilidade do código
9. **[Padrões de Projeto](./padroes-projeto/)** - Soluções reutilizáveis para problemas comuns

## 🎯 Como Seguir o Laboratório

1. **Ordem Sequencial**: Siga os módulos na ordem apresentada
2. **Prática Constante**: Cada módulo inclui exercícios práticos
3. **Projetos Reais**: Construa projetos para consolidar o aprendizado
4. **Revisão Regular**: Revise conceitos anteriores periodicamente

## 📖 Pré-requisitos

- Computador com acesso à internet
- Vontade de aprender e dedicar tempo regular aos estudos
- Mentalidade aberta para resolver problemas

## 🚀 Por Onde Começar

Inicie pelo módulo de **[Lógica de Programação](./logica-de-programacao/)**, pois é a base para todos os demais módulos.
