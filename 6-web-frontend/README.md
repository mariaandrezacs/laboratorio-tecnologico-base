# Roteiro de Aprendizado - Desenvolvimento Web Frontend

Este roteiro foi desenvolvido para guiar você no aprendizado de desenvolvimento web frontend, criando interfaces modernas e interativas.

## 📋 Estrutura do Roteiro

O roteiro está organizado em módulos progressivos. Cada módulo deve ser concluído antes de avançar para o próximo.

---

## 🎯 Módulo 1: Fundamentos da Web

### Objetivos
- Compreender como a web funciona
- Entender o ciclo de requisição-resposta
- Conhecer os papéis de frontend e backend

### Tópicos
1. **Como a Web Funciona**
   - Cliente-servidor
   - Protocolo HTTP/HTTPS
   - DNS e domínios
   - Navegadores web

2. **Estrutura de uma Página Web**
   - HTML (estrutura)
   - CSS (apresentação)
   - JavaScript (comportamento)
   - Como os três trabalham juntos

3. **Ferramentas de Desenvolvimento**
   - Editores de código (VS Code)
   - DevTools do navegador
   - Extensões úteis
   - Configuração do ambiente

### Recursos Recomendados
- [MDN Web Docs](https://developer.mozilla.org/pt-BR/)
- [freeCodeCamp](https://www.freecodecamp.org/)
- [W3Schools](https://www.w3schools.com/)

### Exercícios Práticos
- Instalar VS Code e extensões
- Explorar DevTools do navegador
- Criar sua primeira página HTML
- Entender a estrutura de sites populares

## 📄 Módulo 2: HTML Fundamentos

### Objetivos
- Dominar a estrutura HTML
- Aprender tags semânticas
- Compreender acessibilidade

### Tópicos
1. **Estrutura Básica HTML**
   - DOCTYPE, html, head, body
   - Metadados e charset
   - Títulos e descrições
   - Links e recursos externos

2. **Tags Semânticas**
   - header, nav, main, footer
   - section, article, aside
   - h1-h6 (hierarquia)
   - Importância da semântica

3. **Elementos Comuns**
   - Texto (p, span, strong, em)
   - Listas (ul, ol, li)
   - Links (a)
   - Imagens (img)
   - Divisões (div)

4. **Formulários**
   - form, input, label
   - Tipos de input
   - select, textarea
   - button
   - Validação básica

### Exercícios Práticos
- Criar uma página pessoal
- Estruturar um artigo com tags semânticas
- Criar um formulário de contato
- Implementar acessibilidade básica

## 🎨 Módulo 3: CSS Fundamentos

### Objetivos
- Aprender a estilizar páginas com CSS
- Dominar seletores e propriedades
- Compreender o modelo de caixa

### Tópicos
1. **Introdução ao CSS**
   - O que é CSS
   - Três formas de incluir CSS
   - Sintaxe básica
   - Comentários

2. **Seletores**
   - Seletores de elemento
   - Seletores de classe
   - Seletores de ID
   - Seletores de atributo
   - Pseudo-classes e pseudo-elementos
   - Combinadores

3. **Modelo de Caixa (Box Model)**
   - content, padding, border, margin
   - box-sizing
   - display: block vs inline
   - width e height

4. **Cores e Fundo**
   - Cores (hex, rgb, hsl)
   - background-color
   - background-image
   - Opacidade

### Exercícios Práticos
- Estilizar a página pessoal criada
- Usar diferentes seletores
- Praticar box model
- Criar paletas de cores

## 📐 Módulo 4: CSS Layout

### Objetivos
- Dominar técnicas de layout
- Aprender Flexbox e Grid
- Criar layouts responsivos

### Tópicos
1. **Positioning**
   - static, relative, absolute, fixed, sticky
   - z-index
   - overflow

2. **Flexbox**
   - display: flex
   - flex-direction
   - justify-content
   - align-items
   - flex-wrap
   - flex-grow, flex-shrink, flex-basis

3. **CSS Grid**
   - display: grid
   - grid-template-columns/rows
   - grid-gap
   - grid-area
   - align-content, justify-content

4. **Responsividade**
   - Media queries
   - Unidades relativas (%, em, rem, vw, vh)
   - Mobile-first approach
   - Imagens responsivas

### Exercícios Práticos
- Criar um layout com Flexbox
- Criar um layout com Grid
- Tornar um site responsivo
- Implementar menu mobile

- Aprender a lógica de JavaScript

### Tópicos

## 🔧 Módulo 6: JavaScript Intermediário

### Objetivos
- Dominar funções e objetos
- Aprender arrays e métodos
- Compreender DOM manipulation

### Tópicos
1. **Funções**
   - Declaração de funções
   - Arrow functions
   - Parâmetros e retorno
   - Escopo e closures
   - High-order functions

2. **Arrays**
   - Criação e acesso
   - Métodos (push, pop, shift, unshift)
   - Iteração (forEach, map, filter, reduce)
   - Spread operator

3. **Objetos**
   - Criação de objetos
   - Propriedades e métodos
   - Destructuring
   - Object methods

4. **DOM Manipulation**
   - Selecionar elementos
   - Modificar conteúdo
   - Adicionar/remover elementos
   - Event listeners
   - Event bubbling

### Exercícios Práticos
- Criar lista de tarefas interativa
- Implementar slider de imagens
- Criar modal
- Fazer validação de formulário em tempo real

## 🔒 Módulo 11: Segurança Frontend

### Objetivos
- Compreender riscos de segurança
- Aprender boas práticas
- Implementar proteções básicas

### Tópicos
1. **Ameaças Comuns**
   - XSS (Cross-Site Scripting)
   - CSRF (Cross-Site Request Forgery)
   - Clickjacking
   - Injection attacks

2. **Boas Práticas**
   - Validação de entrada
   - Sanitização de dados
   - Content Security Policy (CSP)
   - HTTPS
   - Autenticação segura

3. **Segurança em APIs**
   - Tokens (JWT)
   - CORS
   - Rate limiting
   - Proteção de dados sensíveis

### Exercícios Práticos
- Implementar CSP
- Validar entrada de usuário
- Usar tokens de autenticação
- Configurar CORS corretamente

## 🎯 Dicas de Estudo

1. **Construa projetos reais** - A melhor forma de aprender é praticando
2. **Use DevTools** - Domine as ferramentas do navegador
3. **Aprenda a debugar** - Debugging é uma habilidade essencial
4. **Siga boas práticas** - Código limpo e organizado
5. **Fique atualizado** - O mundo frontend muda rápido
6. **Construa um portfólio** - Mostre seu trabalho
7. **Participe da comunidade** - GitHub, Stack Overflow, fóruns
